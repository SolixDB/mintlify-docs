## What Data Can We Deliver?

SolixDB specializes in Solana DeFi transaction data with parsed instruction types:

### Supported Protocols

- **DEX Aggregators**: Jupiter V4/V6, Raydium AMM V3, Raydium CP Swap
- **Lending**: Kamino Lending, Kamino Lending Vault
- **Farms**: Kamino Farms
- **Liquidity**: Kamino Limo, Meteora DLMM, Meteora DAMM V2, Meteora Dynamic Bonding Curve
- **Trading**: Drift V2, Pump.fun, Pump AMM
- **DEX**: Orca Whirlpool

### Data Fields

Each transaction record includes:

- Transaction signature
- Slot and block time
- Program ID
- Protocol name
- Instruction type (parsed from IDL)
- Success status
- Fee and compute units
- Account counts
- Failed transaction details (error messages, logs)
