The SolixDB API is **publicly accessible** and does not require any authentication. There is no API key system—simply make requests and we track usage by IP address.

## No Authentication Required

You can start making requests immediately—no API keys, no tokens, no sign-up required. Simply make requests to our API endpoints and we'll track usage based on your IP address.

## Rate Limiting

Rate limiting is applied per IP address to ensure fair usage:

- **Default Limit:** 100 requests per minute per IP address
- **Window:** 60 seconds (1 minute)

<Note>
  Rate limit information is included in response headers. See our [Rate Limiting](/rate-limiting) guide for details.
</Note>

## Making Requests

### REST API

<CodeGroup>
```bash
curl -X GET "https://api.solixdb.xyz/api/v1/transactions"
```

```javascript JavaScript
const response = await fetch('https://api.solixdb.xyz/api/v1/transactions');
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get('https://api.solixdb.xyz/api/v1/transactions')
print(response.json())
```
</CodeGroup>

### GraphQL

<CodeGroup>
```bash
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{"query": "{ stats { totalTransactions } }"}'
```

```javascript JavaScript
const response = await fetch('https://api.solixdb.xyz/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    query: '{ stats { totalTransactions } }'
  })
});
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    'https://api.solixdb.xyz/graphql',
    json={'query': '{ stats { totalTransactions } }'}
)
print(response.json())
```
</CodeGroup>
