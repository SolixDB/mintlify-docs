## What to Include in Support Requests

To help us help you faster, please include:

### For API Issues

- API endpoint you're calling
- Request payload (redact your API key)
- Response you received
- Expected behavior
- Error messages or logs

### For Data Questions

- Protocol name
- Date range
- Specific data fields you're looking for
- Example queries you've tried

### For Feature Requests

- Use case description
- Why this feature would be valuable
- Example of how you'd use it
