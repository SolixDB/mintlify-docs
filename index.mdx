Whether you're building trading bots, analytics dashboards, ML models, or conducting research, our GraphQL API gives you the power to query DEX data with composable query primitives.

## Base URL

All API requests should be made to:

```
https://api.solixdb.xyz
```

**GraphQL Endpoint:**
```
POST /graphql
```

## Quick Start

Make your first GraphQL query in seconds:

<CodeGroup>
```bash GraphQL
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ transactions(filters: { protocols: [\"jupiter_v6\"] }, pagination: { first: 10 }) { edges { node { signature protocolName fee } } } }"
  }'
```

```bash REST API (Legacy)
curl -X GET "https://api.solixdb.xyz/api/v1/transactions?protocol_name=jupiter_v6&limit=10"
```

```bash SQL Query (Legacy)
curl -X POST "https://api.solixdb.xyz/api/v1/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = '\''jupiter_v6'\'' LIMIT 10"
  }'
```
</CodeGroup>

<Info>
  **New to GraphQL?** We recommend using the GraphQL API for new projects. It provides better flexibility, performance, and advanced features. See our [Migration Guide](/api-reference/migration-guide) if you're currently using the REST API.
</Info>

SolixDB powers a wide range of applications:

- **Trading Bots**: Backtest strategies against historical DEX trades with flexible queries
- **Analytics Dashboards**: Monitor protocol performance and trends with real-time aggregations
- **ML Models**: Export training datasets with background job processing and sampling

## Key Features

### Flexible Queries

Query exactly the fields you need with GraphQL:

```graphql
query {
  transactions(
    filters: {
      protocols: ["pump_fun"]
      dateRange: { start: "2025-01-01", end: "2025-01-31" }
    }
    groupBy: [PROTOCOL, HOUR]
    metrics: [COUNT, AVG_FEE, P95_COMPUTE_UNITS]
  ) {
    edges {
      node {
        protocol
        hour
        count
        avgFee
        p95ComputeUnits
      }
    }
  }
}
```

### Query Complexity

Check complexity before execution:

```graphql
query {
  queryComplexity(
    filters: { dateRange: { start: "2025-01-01", end: "2025-01-31" } }
    groupBy: [PROTOCOL, HOUR]
  ) {
    score
    estimatedRows
    recommendations
  }
}
```

### ML Dataset Export

Export datasets for training with background processing:

```graphql
mutation {
  exportDataset(
    config: {
      format: PARQUET
      filters: { protocols: ["pump_fun"] }
      columns: ["protocol_name", "fee", "compute_units"]
      sampling: { strategy: RANDOM, rate: 0.1 }
    }
  ) {
    id
    status
    progress
  }
}
```
