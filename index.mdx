SolixDB provides fast and flexible access to **390M+ Solana transaction instruction records** stored in ClickHouse. Whether you're building analytics dashboards, monitoring protocol activity, or conducting research, our API gives you the power to query transaction data with ease.

## Base URL

All API requests should be made to:

```
https://api.solixdb.xyz
```

## Quick Start

Make your first request in seconds:

<CodeGroup>
```bash REST API
curl -X GET "https://api.solixdb.xyz/api/v1/transactions?protocol_name=jupiter_v6&limit=10"
```

```bash GraphQL
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ transactions(protocolName: \"jupiter_v6\", limit: 10) { signature protocolName fee } }"
  }'
```

```bash SQL Query
curl -X POST "https://api.solixdb.xyz/api/v1/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = '\''jupiter_v6'\'' LIMIT 10"
  }'
```
</CodeGroup>
