This guide will help you get started with the SolixDB API and make your first request.

## Prerequisites

- HTTP client (curl, Postman, or your preferred tool)
- Basic understanding of REST APIs and/or GraphQL
- API key (contact support to obtain one)

## Making Your First Request

### REST API Example

<CodeGroup>
```bash
curl -X GET "https://api.solixdb.xyz/api/v1/transactions?protocol_name=jupiter_v6&limit=10" \
  -H "X-API-Key: your-api-key"
```

```javascript JavaScript
const response = await fetch('https://api.solixdb.xyz/api/v1/transactions?protocol_name=jupiter_v6&limit=10', {
  headers: {
    'X-API-Key': 'your-api-key'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

headers = {
    'X-API-Key': 'your-api-key'
}

response = requests.get(
    'https://api.solixdb.xyz/api/v1/transactions',
    headers=headers,
    params={
        'protocol_name': 'jupiter_v6',
        'limit': 10
    }
)

print(response.json())
```
</CodeGroup>

### GraphQL Example

<CodeGroup>
```bash
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{
    "query": "{ transactions(protocolName: \"jupiter_v6\", limit: 10) { signature protocolName fee } }"
  }'
```

```javascript JavaScript
const query = `
  query {
    transactions(protocolName: "jupiter_v6", limit: 10) {
      signature
      protocolName
      fee
    }
  }
`;

const response = await fetch('https://api.solixdb.xyz/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': 'your-api-key'
  },
  body: JSON.stringify({ query })
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

query = """
{
  transactions(protocolName: "jupiter_v6", limit: 10) {
    signature
    protocolName
    fee
  }
}
"""

response = requests.post(
    'https://api.solixdb.xyz/graphql',
    json={'query': query},
    headers={'X-API-Key': 'your-api-key'}
)

print(response.json())
```
</CodeGroup>

### SQL Query Example

Execute custom SQL queries directly against the database:

<CodeGroup>
```bash
curl -X POST "https://api.solixdb.xyz/api/v1/query" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{
    "query": "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = '\''jupiter_v6'\'' LIMIT 10"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.solixdb.xyz/api/v1/query', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': 'your-api-key'
  },
  body: JSON.stringify({
    query: "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = 'jupiter_v6' LIMIT 10"
  })
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    'https://api.solixdb.xyz/api/v1/query',
    json={
        'query': "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = 'jupiter_v6' LIMIT 10"
    },
    headers={'X-API-Key': 'your-api-key'}
)

print(response.json())
```
</CodeGroup>

<Warning>
  **SQL Query Restrictions:** SQL queries must include a LIMIT clause and are read-only (SELECT only). Maximum LIMIT value is 10,000 rows.
</Warning>

## Response Format

All successful REST API responses follow this format:

```json
{
  "data": [
    {
      "signature": "5KJp...",
      "slot": 123456789,
      "blockTime": 1721491200,
      "programId": "JUP6LkbZbjS1jKKwapdHNy74zcZ3tLUZoi5QNyVTaV4",
      "protocolName": "jupiter_v6",
      "instructionType": "swap",
      "fee": 5000,
      "computeUnits": 200000,
      "accountsCount": 10,
      "date": "2025-07-20",
      "hour": 12
    }
  ],
  "count": 100,
  "limit": 100,
  "offset": 0
}
```
