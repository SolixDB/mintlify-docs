This guide will help you get started with the SolixDB API and make your first request to query Solana DeFi data.

## Prerequisites

- HTTP client (curl, Postman, or your preferred tool)
- Basic understanding of REST APIs, GraphQL, or SQL

## Making Your First Request

### REST API Example

The simplest way to get started is with our REST API:

<CodeGroup>
```bash
curl -X GET "https://api.solixdb.xyz/api/v1/transactions?protocol_name=jupiter_v6&limit=10"
```

```javascript JavaScript
const response = await fetch('https://api.solixdb.xyz/api/v1/transactions?protocol_name=jupiter_v6&limit=10');

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    'https://api.solixdb.xyz/api/v1/transactions',
    params={
        'protocol_name': 'jupiter_v6',
        'limit': 10
    }
)

print(response.json())
```
</CodeGroup>

### GraphQL Example

For more flexible queries, use our GraphQL API:

<CodeGroup>
```bash
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ transactions(protocolName: \"jupiter_v6\", limit: 10) { signature protocolName fee } }"
  }'
```

```javascript JavaScript
const query = `
  query {
    transactions(protocolName: "jupiter_v6", limit: 10) {
      signature
      protocolName
      fee
    }
  }
`;

const response = await fetch('https://api.solixdb.xyz/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ query }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

query = """
  query {
    transactions(protocolName: "jupiter_v6", limit: 10) {
      signature
      protocolName
      fee
    }
  }
"""

response = requests.post(
    'https://api.solixdb.xyz/graphql',
    json={'query': query}
)

print(response.json())
```
</CodeGroup>

### SQL Query Example

For maximum flexibility, execute custom SQL queries directly:

<CodeGroup>
```bash
curl -X POST "https://api.solixdb.xyz/api/v1/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = '\''jupiter_v6'\'' LIMIT 10"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.solixdb.xyz/api/v1/query', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    query: "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = 'jupiter_v6' LIMIT 10"
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    'https://api.solixdb.xyz/api/v1/query',
    json={
        'query': "SELECT signature, protocol_name, fee FROM transactions WHERE protocol_name = 'jupiter_v6' LIMIT 10"
    }
)

print(response.json())
```
</CodeGroup>

## Understanding the Response

All API responses follow a consistent structure:

```json
{
  "data": [...],
  "meta": {
    "count": 10,
    "limit": 10,
    "offset": 0
  }
}
```

## Supported Protocols

Currently, we support the following DEX protocols:

- `jupiter_v4` - Jupiter Aggregator V4
- `jupiter_v6` - Jupiter Aggregator V6
- `raydium_amm_v3` - Raydium AMM V3
- `raydium_cp_swap` - Raydium CP Swap
- `pump_fun` - Pump.fun
- `pump_amm` - Pump AMM
- `whirlpool` - Orca Whirlpool

<Note>
  We're continuously adding support for more protocols. Check our [changelog](https://github.com/solixdb) for updates.
</Note>
