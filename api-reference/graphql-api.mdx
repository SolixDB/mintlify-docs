The GraphQL API provides flexible querying with exactly the data you need.

## Endpoint

```
POST /graphql
```

## Authentication

The API is **publicly accessible** and does not require authentication. Rate limiting is applied per IP address.

## Schema

### Types

#### Transaction

```graphql
type Transaction {
  signature: String!
  slot: Int!
  blockTime: Int!
  programId: String!
  protocolName: String!
  instructionType: String!
  fee: Int!
  computeUnits: Int!
  accountsCount: Int!
  date: String!
  hour: Int!
}
```

#### ProtocolAnalytics

```graphql
type ProtocolAnalytics {
  protocolName: String!
  totalTransactions: Int!
  totalFees: Int!
  totalComputeUnits: Int!
  averageFee: Float!
  averageComputeUnits: Float!
  uniquePrograms: Int!
  dateFrom: String
  dateTo: String
}
```

#### TimeSeriesPoint

```graphql
type TimeSeriesPoint {
  timestamp: String!
  value: Int!
  label: String
}
```

#### FeeAnalytics

```graphql
type FeeAnalytics {
  minFee: Int!
  maxFee: Int!
  avgFee: Float!
  medianFee: Float!
  p95Fee: Float!
  p99Fee: Float!
  totalFees: Int!
}
```

#### Stats

```graphql
type Stats {
  totalTransactions: Int!
  totalFailedTransactions: Int!
  dateRange: DateRange!
  protocols: [ProtocolCount!]!
}

type DateRange {
  from: String!
  to: String!
}

type ProtocolCount {
  name: String!
  count: Int!
}
```

## Queries

### transactions

Query transactions with filters.

**Arguments:**

| Argument | Type | Required | Description |
|----------|------|----------|-------------|
| `protocolName` | String | No | Filter by protocol |
| `programId` | String | No | Filter by program ID |
| `dateFrom` | String | No | Start date (YYYY-MM-DD) |
| `dateTo` | String | No | End date (YYYY-MM-DD) |
| `signature` | String | No | Filter by signature |
| `limit` | Int | No | Number of results (default: 100) |
| `offset` | Int | No | Number to skip (default: 0) |

<CodeGroup>
```graphql
query {
  transactions(
    protocolName: "jupiter_v6"
    dateFrom: "2025-07-20"
    limit: 10
  ) {
    signature
    protocolName
    fee
    computeUnits
    blockTime
  }
}
```

```bash curl
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ transactions(protocolName: \"jupiter_v6\", dateFrom: \"2025-07-20\", limit: 10) { signature protocolName fee computeUnits blockTime } }"
  }'
```
</CodeGroup>

```graphql
    fee
    computeUnits
    blockTime
  }
}
```

```bash curl

  -H "Content-Type: application/json" \
  -d '{
    "query": "{ transaction(signature: \"5KJp...\") { signature protocolName fee computeUnits blockTime } }"

```
</CodeGroup>

### protocolAnalytics

Get analytics for a protocol.

**Arguments:**

| Argument | Type | Required | Description |
|----------|------|----------|-------------|
| `protocolName` | String | Yes | Protocol name |
| `dateFrom` | String | No | Start date |
| `dateTo` | String | No | End date |

<CodeGroup>
```graphql
query {
  protocolAnalytics(
    protocolName: "jupiter_v6"
    dateFrom: "2025-07-20"
  ) {
    protocolName
    totalTransactions
    totalFees
    averageFee
    uniquePrograms
  }
}
```

```bash curl
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ protocolAnalytics(protocolName: \"jupiter_v6\", dateFrom: \"2025-07-20\") { protocolName totalTransactions totalFees averageFee uniquePrograms } }"
  }'
```
</CodeGroup>

### timeSeries

Get time series data.

**Arguments:**

| Argument | Type | Required | Description |
|----------|------|----------|-------------|
| `protocolName` | String | No | Filter by protocol |
| `dateFrom` | String | Yes | Start date |
| `dateTo` | String | Yes | End date |
| `granularity` | String | No | `hour` or `day` (default: `hour`) |

<CodeGroup>
```graphql
query {
  timeSeries(
    protocolName: "jupiter_v6"
    dateFrom: "2025-07-20"
    dateTo: "2025-07-21"
    granularity: "hour"
  ) {
    timestamp
    value
  }
}
```

```bash curl
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ timeSeries(protocolName: \"jupiter_v6\", dateFrom: \"2025-07-20\", dateTo: \"2025-07-21\", granularity: \"hour\") { timestamp value } }"
  }'
```
</CodeGroup>

Get global statistics.

<CodeGroup>
```graphql

  stats {
    totalTransactions

      from
      to

      count
    }
  }

```

```bash curl
curl -X POST "https://api.solixdb.xyz/graphql" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ stats { totalTransactions totalFailedTransactions dateRange { from to } protocols { name count } } }"
```

</CodeGroup>

```javascript
const query = `
  query {
    transactions(protocolName: "jupiter_v6", limit: 5) {
      signature
      protocolName
      fee
    }
  }
`;

const response = await fetch('https://api.solixdb.xyz/graphql';
  method: 'POST',
}
"""

response = requests.post(
    'https://api.solixdb.xyz/graphql',
    json={'query': query},
)

data = response.json()
print(data)
```
